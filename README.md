# BOXAR

واجهة البداية لتطبيق BOXAR، منصة عربية لتعلّم البرمجة من الصفر.

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو استخدم أي خادم ملفات ثابت مثل:

```bash
npx serve .
```

## الموجود حاليًا

- صفحة رئيسية عربية RTL بتصميم متجاوب.
- مسارات تمهيدية لـ Python وHTML/CSS وJavaScript.
- مختبر كود تفاعلي بسيط.
- وضع ليلي مع حفظ التفضيل.
- تصميم يعمل على الجوال والكمبيوتر.

## الخطوة التالية

إضافة نظام دروس حقيقي، حسابات مستخدمين، وحفظ تقدّم المتعلم على الخادم.

# BOXAR

## النسخة 2: مسار تعلم بايثون بالعربية

- 50 بطاقة مفردات مع معنى الكلمة واستخدامها.
- نظام حفظ تقدّم محلي مع فلاتر: الكل، المحفوظة، والجديدة.
- اختبار قصير يثبت الفهم.
- مراحل واضحة: الكلمات ← الاختبار ← كتابة الكود ← المشاريع.
- تسجيل دخول تجريبي يحفظ الاسم والبريد على الجهاز.
- وضع ليلي وتصميم متجاوب.

### ملاحظة قاعدة البيانات
هذه النسخة تعمل مباشرة على GitHub Pages، لذلك تستخدم `localStorage` كي ترى الفكرة دون خادم. تسجيل الدخول الحقيقي والمزامنة بين الأجهزة يحتاجان Backend مثل Supabase أو Firebase، وسأضيفهما بعد اختيار مزود قاعدة البيانات وإضافة مفاتيح المشروع بأمان في إعدادات النشر.

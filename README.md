# BOXAR

منصة عربية للمكتبات الرقمية والكتب المتخصصة في التاريخ، الدين، الرياضيات، العلوم، الأدب، والفلسفة. المشروع الحالي هو نسخة جاهزة للتجربة عملت داخل المستودع باستخدام HTML وCSS وJavaScript، مع واجهة عربية RTL، تصميم متجاوب، بحث، تصنيفات، كتب مميزة، ومفضلة.

## ماذا يحتوي المشروع
- واجهة عربية كاملة من اليمين إلى اليسار
- شريط بحث
- تصنيفات متعددة
- قائمة كتب مميزة
- عرض كل الكتب
- إضافة/إزالة من المفضلة
- نافذة تفاصيل الكتاب
- نسخة متجاوبة للموبايل
- تنسيق بصري مستوحى من هوية BOXAR

## التشغيل
افتح الملف `index.html` مباشرة في المتصفح، أو شغّله من خادم محلي:

```bash
python -m http.server 8000
```

ثم افتح الرابط:

```bash
http://localhost:8000
```

## هيكل المشروع
- `index.html` — هيكل الصفحة
- `styles.css` — التنسيق والهوية البصرية
- `app.js` — البيانات ومنطق التطبيق

## ملاحظة مهمة
هذا الإصدار موجه للتجربة السريعة والتصميم الوظيفي. لاحقًا يمكن ربطه بـ Supabase أو Firebase، وإضافة قاعدة بيانات حقيقية، تسجيل دخول، رفع الكتب، ودعم PDF/EPUB.

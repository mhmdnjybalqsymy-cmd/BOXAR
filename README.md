# BOXAR

منصة عربية لتحويل وصف الروبوت إلى تصميم ثلاثي الأبعاد، مخطط توصيل، قائمة قطع، وكود قابل للتنفيذ.

## MVP الحالي
- واجهة عربية RTL بتصميم مستقبلي متجاوب.
- مولد اقتراحات يعتمد على وصف المستخدم (سيارة، ذراع، روبوت حارس).
- مساحة محاكاة 3D تفاعلية أولية مع تشغيل/إيقاف ومؤشرات.
- مكتبة قطع إلكترونية.
- حفظ المشروع محليًا وتبديل المظهر.
- جولة تعريفية ورسائل حالة واضحة.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو استخدم أي خادم ملفات ثابت:

```bash
npx serve .
```

هذه نسخة واجهة MVP بدون خادم. الخطوة التالية هي ربط واجهات الذكاء الاصطناعي، محرك الفيزياء، ومولد الكود الفعلي.
